# 价值投机原则

> **草稿。** 这份提纲留给仓库所有者改写。它不是策略参数，也不是可执行规则。插件在接入之前不得把这里的句子当成交易指令。

价值投机在本产品里分成三层讨论，再加一条硬性要求：每一笔拟议交易都要有一段可以拿出来讨论的自然语言论点。

## 三层

### 宏观

看流动性、利率、信用与风险偏好这一类大环境。宏观层只提供背景，不单独构成下单理由。对应插件：`plugins/value-spec-macro`。

### 行业周期

看行业处在周期的哪一段，以及供需、政策或资本开支这类约束如何传到个股。行业层连接宏观背景和微观标的。对应插件：`plugins/value-spec-industry`。

### 微观（技术 + 情绪）

看个股自身的价格结构与市场情绪。技术面和情绪是讨论材料，不是自动信号。对应插件：`plugins/value-spec-micro`。

三层是讨论结构。上一层为下一层提供背景；没有写完的一层，不应该被下一层假装已经考虑过。

## 交易论点

每一笔拟议交易都必须有一段自然语言论点，并且这段话本身要能够被讨论。至少写清：

- 在看什么
- 为什么现在值得讨论
- 论点在什么情况下失效

没有论点，就不进入交易门禁。对应插件：`plugins/trade-thesis`。门禁本身见 `plugins/trade-gate`。
