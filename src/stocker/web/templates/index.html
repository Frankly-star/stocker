执行模式
控制 Supervisor 是否允许执行实际交易。分析、风险评估、状态查询等操作不受此限制，Supervisor 会根据对话意图自动调度。
OBSERVE — 观察模式
Supervisor 正常运行所有分析和评估流程，但不会执行任何实际交易。适合研究、回测和日常监控。这是默认的安全模式。
ACTIVE — 执行模式
Supervisor 拥有完整自主权，分析后可直接通过 Broker 执行交易。适合实盘或模拟盘自动交易场景。
自动投研 (AutoPilot)
开启后 Supervisor 将定期自主执行：行业研究 → 选股 → 信号扫描 → 深度分析 → 自动建仓/平仓。需配合 ACTIVE 模式才会实际交易。
AutoPilot — 已关闭
点击切换。开启后每小时自动执行一轮投研周期：发现行业机会 → 添加观察股 → 扫描信号 → 分析评估 → 交易执行。
Supervisor 会根据你的对话意图自动决定执行什么操作（分析、评估、查询状态、管理持仓等），无需手动选择流程。唯一需要你控制的是：是否允许执行实际交易。
